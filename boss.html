System Architecture

Typical application scenarios

The platform scales from a single rack to a full 2.5MW plant using the same three building blocks.

One PCS supports up to 16 racks of batteries in parallel

Each PCS aggregates up to 16 battery clusters into a battery stack; multiple stacks (up to 4 PCS units) connect back to a single STS module.

One STS module connects up to four 125kW PCS modules

Each PCS pairs with its own MPPT stage for PV input, giving a 4×125kW = 500kW block per STS module.

Five STS modules scale the system to 2.5MW

Five STS modules, each supporting four 125kW PCS units, combine for a full twenty-PCS, 2.5MW installation.
